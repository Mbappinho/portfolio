# Portfolio — Édition N°1

Revue personnelle en ligne de **Théo Bourgeois** : un portfolio conçu comme le numéro 1 d'un magazine imprimé (éditorial brutalisé, 100 % français).

## Stack

React 19 · TypeScript · Vite 7 · Tailwind CSS 3.4 · GSAP + ScrollTrigger · Framer Motion · Lenis

## Développement

```bash
npm install
npm run dev
npm run build
```

## Contenu

Couverture, manifeste, rubriques de compétences, deux grands reportages (localisation française de Welcome to the Game III, Tarkov Barter Scanner), hors-champ (passions) et colophon (contact).
